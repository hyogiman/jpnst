홈 화면에 바로 설치가장 쉬워요

버튼을 누르고 설치를 한 번 더 누르면 홈 화면과 앱 목록에 アニ耳 아이콘이 생겨요. 파일을 내려받지 않아 경고 창이 없고, 새 버전도 저절로 받아요.

설치 창이 안 뜨면 Chrome 오른쪽 위 메뉴 → 앱 설치 또는 홈 화면에 추가 → 설치를 누르세요. 이미 설치했다면 홈 화면이나 앱 목록에서 アニ耳를 찾아 여세요.
삼성 인터넷 등 다른 브라우저라면 메뉴에서 홈 화면에 추가를 찾거나, Chrome에서 열기를 눌러 주세요.

인터넷 없이 쓰려면: 앱 파일(APK)

음성까지 모두 들어 있는 앱 파일이에요. 비행기 모드에서도 모든 글자·음성으로 공부할 수 있어요. Play 스토어 밖의 파일이라 설치할 때 확인 창이 몇 번 나와요.

앱 파일 받기 (APK · 약 130MB)

설치 순서 · 잘 안 될 때 보기

홈 화면 앱과 앱 파일은 학습 기록이 따로 저장돼요. 옮길 때는 나 → 백업 내보내기 후 다른 쪽에서 백업 불러오기.

홈 화면에 추가하기

아이폰은 App Store 밖의 앱 파일을 설치할 수 없어서, Safari의 '홈 화면에 추가'로 설치해요. 홈 화면 아이콘으로 열면 앱처럼 전체 화면으로 열려요.

  1. 아래 버튼을 눌러 アニ耳를 엽니다.Safari에서 アニ耳 열기
  2. 공유 버튼을 누릅니다.
    화면 아래에 공유 버튼이 없으면(iOS 26 기본 화면) 오른쪽 아래 버튼을 먼저 누르세요. 아이패드는 화면 위쪽을 보세요.
  3. 주소창 오른쪽의 공유 버튼을 누릅니다. (iOS 16.4 이상의 Chrome)
  4. 목록을 내려 홈 화면에 추가를 누르고, 오른쪽 위 추가를 누르면 끝이에요.
잘 안 될 때
  • '홈 화면에 추가'가 안 보여요 · 공유 목록을 끝까지 내려 보세요. 카카오톡 등 다른 앱 안에서 열었다면 Safari에서 다시 열어야 보여요.
  • Safari에서 하던 기록이 안 보여요 · 홈 화면 앱은 기록을 따로 저장할 수 있어요. Safari의 나 → 백업 내보내기 후 홈 화면 앱에서 백업 불러오기.
  • 인터넷이 없을 때 · 한 번 연 화면과 받아 둔 음성은 저장돼 있어서 인터넷 없이도 열려요.
