# アニ耳 구글 플레이 스토어 등록 자료 (한국어)

Play Console → **스토어 등록정보 → 기본 스토어 등록정보**에 붙여 넣는 글과 그림입니다.
글자 수는 플레이 제한 안에 맞춰 두었습니다. 괄호 안 숫자는 실제 글자 수(공백 포함)입니다.
진행 순서 전체는 [docs/PLAY-STORE.md](../docs/PLAY-STORE.md)를 보세요.

---

## 1. 앱 이름 (최대 30자)

| | 이름 | 글자 수 |
|---|---|---:|
| **추천** | `アニ耳 - 애니 청해 일본어 180일` | 20 |
| 다른 안 | `アニ耳: 애니로 배우는 일본어 듣기` | 19 |

- 홈 화면 아이콘 아래 이름(`アニ耳 일본어`)은 앱 안에 들어 있는 이름이라 이 칸과 따로입니다.
- 플레이 메타데이터 정책상 이름에 '무료', '최고', '1위', 이모티콘, 다른 앱·작품 이름을 넣으면 안 됩니다.

## 2. 간단한 설명 (최대 80자)

| | 문구 | 글자 수 |
|---|---|---:|
| **추천** | `히라가나부터 애니 대사까지, 하루 한 화씩 귀로 익히는 180일 일본어 청해 코스` | 45 |
| 다른 안 | `일본어를 처음 배우는 한국어 화자를 위한 애니 청해 180일. 매일 평가와 간격 반복으로 오래 남게.` | 56 |

## 3. 자세한 설명 (최대 4000자)

아래 상자 안의 글 전체를 붙여 넣으세요. (1,580자)

```text
애니메이션을 자막 없이 알아듣고 싶은데, 일본어는 하나도 모르시나요?
アニ耳(아니미미, '애니를 듣는 귀')는 일본어를 처음 배우는 한국어 화자가 하루 한 화(20~30분)씩 180일 동안 공부해, 애니 대사를 알아듣는 청해 기초를 만드는 학습 앱입니다.

■ 180화 코스
· 학습 144화 · 보스전 24화 · 청해 특훈 6화 · 승급 시험 6화
· 히라가나·가타카나 221자 → 단어·표현 1,154개 → 문법·표현 196개(예문 496개) → 애니 대사 139개 → 장면 대화 24편
· F급 견습 모험가에서 시작해, 챕터마다 승급 시험을 통과하면 랭크가 올라갑니다.

■ 하루 한 화의 흐름
워밍업 복습 → 새로 배우기 → 연습 → 오늘의 애니 대사 → 인문학 한 스푼 → 오늘의 평가
· 매 화 마지막 평가(10문항)에서 70점을 넘어야 다음 화가 열립니다. 90점 이상이면 하나마루!
· 틀린 문제는 간격 반복(SRS)으로 알맞은 날에 다시 나옵니다.
· 주마다 보스전, 챕터마다 승급 시험으로 배운 것을 다시 묶어 확인합니다.

■ 듣기에 집중하도록 만든 장치
· 모든 글자·단어·예문·대사에 일본어 음성이 있습니다. 남녀 목소리 4개를 섞어 들려주고, 설정에서 한 목소리만 고를 수도 있어요.
· 문제에는 가나만 보여 주고, 한자·로마자는 답을 고른 뒤에 공개합니다. 조금 애써 떠올린 것이 더 오래 남는다는 '바람직한 어려움' 연구를 따랐습니다. (설정에서 힌트를 켤 수 있어요)
· 장면 대화는 한국어 자막 → 일본어 자막 → 자막 없음 순서로 단계를 올려 가며 듣습니다.
· 애니 대사는 천천히(0.75배)·보통·애니 속도(1.25배)로 듣고 따라 말하기(쉐도잉)를 합니다.
· 청해 특훈은 소리만으로 15문항을 풀고, 5문항마다 속도가 빨라집니다.
· 글자마다 한국어 기억법, 글자가 나온 한자, 따라 쓰기 연습이 있습니다.

■ 인문학 한 스푼 (144편)
매 화 끝에 언어·문화·철학·심리학으로 생각을 넓히는 짧은 읽을거리와 질문이 있습니다.
예) 히라가나는 어떻게 태어났을까 / 나를 부르는 말이 캐릭터를 만든다 — 역할어 / 하이쿠는 글자가 아니라 박자를 센다 / いただきます에 담긴 것

■ 꾸준히 하게 돕는 장치
연속 학습과 보호권, 레벨·경험치, 스탬프 카드, 배지, 능력치와 평가 점수 그래프

■ 인터넷 없이도
화면·음성·글꼴이 모두 앱 안에 들어 있어 지하철이나 비행기에서도 공부할 수 있습니다.

■ 미리 알려 드릴 점
· 실제 애니메이션의 영상·음성은 들어 있지 않습니다. 대사와 장면 대화는 애니에서 자주 들리는 말투를 바탕으로 학습용으로 새로 쓴 문장입니다.
· 음성은 사람 성우가 아니라 음성 합성(TTS)으로 만든 일본어 녹음입니다.
· 홈과 나(기록) 화면 아래에 작은 배너 광고가 하나 있습니다. 레슨·평가 중에는 광고가 나오지 않습니다.
· 회원가입이 없고, 학습 기록은 이 기기 안에만 저장됩니다. 앱을 지우면 기록도 지워지니 '나 → 백업 내보내기'로 가끔 백업해 주세요.
· 만 18세 이상을 대상으로 합니다.

개인정보처리방침: https://2nhyeok.kr/privacy/
문의: https://github.com/hyogiman/jpnst/issues
```

> 글 안의 수량(221자, 1,154개 등)은 `node tools/validate.js` 결과와 같습니다. 콘텐츠를 늘리면 이 숫자도 함께 고치세요.

## 4. 그래픽 (이 폴더의 파일)

| 칸 | 파일 | 규격 |
|---|---|---|
| 앱 아이콘 | `icon-512.png` | 512×512 PNG. 꽉 찬 정사각형(둥근 모서리와 그림자는 플레이가 입힘) |
| 그래픽 이미지(대표 이미지) | `feature-graphic.png` | 1024×500 PNG |
| 휴대전화 스크린샷 | `screenshot-1.png` ~ `screenshot-7.png` | 1080×1920 PNG, 7장 (플레이는 2~8장) |

스크린샷 순서(올리는 순서 = 스토어에 보이는 순서):

1. 홈 — 오늘 이어서 할 화, 스탬프 카드
2. 글자 카드 — あ의 기억법·기원 한자(安)·예시 단어
3. 듣기 문제 — "들리는 글자를 고르세요"
4. 장면 대화 — 일본어 자막(후리가나) 단계
5. 인문학 한 스푼 — 역할어
6. 나(기록) — 모험가 랭크·연속 학습·평균 점수
7. 설정 — 목소리 고르기·말하기 속도

- 태블릿 스크린샷은 선택 사항이라 비워 두어도 됩니다.
- 스크린샷에는 광고 배너가 없습니다. 플레이는 '광고 포함' 표시를 등록정보에 따로 붙여 줍니다.
- 다시 만들기: `ANIMIMI_STORE=play node tools/build-app.js && npx http-server www -p 8766 &` 다음 `node tools/make-store-assets.js`
