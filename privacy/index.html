개인정보처리방침

アニ耳 (애니 청해 일본어 180일) · 시행일 2026년 10월 19일

요약

  • 회원가입이 없고, 이름·연락처·결제 정보를 받지 않습니다.
  • 학습 기록(진도·점수·설정)은 이 기기 안에만 저장되며, 운영자의 서버로 보내지 않습니다.
  • 구글 플레이 판에는 Google AdMob 광고가 있으며, 광고를 위해 Google이 기기 정보 등을 수집·처리합니다(아래 3번).

1. 적용 범위

이 방침은 아래에 적용됩니다.

  • 구글 플레이에서 받은 アニ耳 앱 (광고 포함)
  • 2nhyeok.kr/apk 또는 GitHub에서 직접 받아 설치한 アニ耳 앱 (광고 없음)
  • 웹사이트 2nhyeok.kr

2. 기기 안에만 저장하는 정보

학습 진도, 평가 점수, 복습 일정, 배지, 설정은 앱의 내부 저장소(웹은 브라우저 저장소)에만 저장됩니다. 운영자는 이 정보에 접근할 수 없습니다.

  • 백업 파일: 사용자가 나 → 백업 내보내기를 누를 때만 만들어지며, 사용자가 고른 곳(드라이브·메신저·메일 등)으로만 보내집니다.
  • Android 자동 백업: 기기의 백업 설정이 켜져 있으면, Android가 앱 데이터를 사용자 본인의 Google 계정 백업에 포함할 수 있습니다. 이는 Google의 기기 백업 기능이며 운영자는 접근할 수 없습니다.
  • 삭제: 앱을 지우거나 나 → 처음부터 다시 시작을 누르면 학습 기록이 지워집니다.

3. 광고 (구글 플레이 판)

구글 플레이 판은 무료로 제공하는 대신 홈과 나(기록) 화면 아래에 Google AdMob 배너 광고를 보여 줍니다. 레슨과 평가 중에는 광고를 보여 주지 않습니다.

직접 설치판에도 광고 코드가 함께 들어 있지만 광고를 켜지 않습니다. 광고 SDK를 초기화하지 않으며, SDK의 앱 측정도 초기화할 때까지 미루도록 설정해 두었습니다.

Google의 광고 SDK는 광고 제공·분석·부정 방지를 위해 IP 주소, 앱 이용 정보(광고 노출·클릭 등), 진단 정보, 기기 식별자(광고 ID 등)를 자동으로 수집해 Google에 보냅니다(Google 안내). 운영자는 이 정보를 직접 받지 않습니다.

수집하는 행태정보광고 ID 등 기기 식별자, 광고 노출·클릭 등 앱 이용 정보, IP 주소
수집 방법앱이 광고를 불러올 때 Google 광고 SDK가 자동으로 수집
목적광고 제공, 맞춤형 광고, 광고 성과 측정, 부정 클릭 방지
처리하는 곳Google LLC — Google의 서버(국외 포함)에서 처리될 수 있음
보유 기간Google의 정책에 따름
거부·통제 방법기기 설정의 Google → 광고(또는 개인정보 보호 → 광고) 메뉴에서 광고 ID를 삭제·재설정하거나 맞춤 광고를 끌 수 있습니다. 메뉴 이름은 기기마다 다를 수 있습니다. 유럽 등 동의가 필요한 지역에서는 앱을 처음 열 때 동의 화면이 나오고, 앱의 나 → 광고 개인정보 설정에서 바꿀 수 있습니다.

Google의 정보 처리 방식: Google이 파트너의 사이트나 앱을 사용할 때 정보를 사용하는 방식, Google 개인정보처리방침

4. 직접 설치판의 새 버전 확인

직접 설치한 앱은 새 버전이 있는지 GitHub(api.github.com)에 6시간에 한 번쯤 물어봅니다. 이때 IP 주소 등 접속 정보가 GitHub에 전달될 수 있습니다(GitHub 개인정보 고지). 구글 플레이 판은 이 확인을 하지 않습니다.

5. 웹사이트 (2nhyeok.kr)

웹사이트는 GitHub Pages로 제공되고, 웹에서는 글꼴을 Google Fonts에서 불러옵니다. 접속할 때 IP 주소 등 접속 정보가 GitHub와 Google에 전달될 수 있습니다. 웹사이트에는 광고가 없습니다.

6. 이용 대상

구글 플레이 판은 만 18세 이상을 대상으로 합니다.

7. 문의와 변경

개인정보와 관련한 문의는 GitHub 문의 게시판 또는 구글 플레이 스토어의 개발자 연락처로 보내 주세요.
