앱 내려받기 (APK)

animimi.apk · 약 120MB · 항상 최신 버전

설치 순서

  1. Chrome 앱에서 위 버튼을 누릅니다. 카카오톡·Claude 등 다른 앱 안의 브라우저는 다운로드가 멈출 수 있어요.
  2. "이 파일은 기기를 손상시킬 수 있습니다" 같은 안내가 나오면 다운로드(그래도 다운로드)를 누릅니다. 직접 만든 앱이라 Play 스토어 밖 파일에 항상 나오는 안내입니다.
  3. 다운로드가 끝나면 열기를 누릅니다. 안 보이면 내 파일 → 다운로드 → animimi.apk를 누르세요.
  4. "출처를 알 수 없는 앱" 안내가 나오면 설정 → 이 출처 허용을 켜고 뒤로 갑니다.
  5. 설치 → 열기. 홈 화면에 'アニ耳 일본어' 아이콘이 생깁니다.

잘 안 될 때

다운로드가 100%에서 멈춰요

파일은 이미 다 받아졌고, "그래도 다운로드할까요?" 확인 창이 가려진 경우가 많아요.

  1. 화면 위에서 아래로 쓸어 알림창에 animimi.apk 알림이 있으면 눌러 보세요.
  2. 내 파일 → 다운로드에 animimi.apk가 있으면 바로 눌러 설치하세요.
  3. 둘 다 없으면 받던 화면을 닫고 Chrome 앱에서 2nhyeok.kr/apk를 열어 다시 받으세요.
"자동 차단 기능에 의해 차단됨"이 떠요 (삼성 갤럭시)

설정 → 보안 및 개인정보 보호 → 자동 차단 기능을 잠시 끄고 설치한 뒤, 설치가 끝나면 다시 켜도 됩니다.

Play 프로텍트가 검사하겠냐고 물어요

앱 검사를 누르고, 검사가 끝나면 설치를 계속하면 됩니다. Play 스토어에 올리지 않은 앱이라 나오는 안내입니다.

"앱이 설치되지 않았습니다"가 떠요

예전에 다른 곳에서 받은 같은 이름의 앱이 있다면 지운 뒤 다시 설치하세요. 그래도 안 되면 저장 공간(약 300MB 여유)을 확인해 주세요.

버튼을 눌러도 받아지지 않아요

GitHub 배포 페이지에서 직접 받을 수 있어요. github.com/hyogiman/jpnst/releases/latest를 열고 맨 아래 Assets의 animimi.apk를 누르세요.

새 버전으로 업데이트하려면

앱 홈에 뜨는 새 버전 안내에서 바로 내려받기를 누르거나, 이 페이지에서 다시 받아 그대로 설치(덮어쓰기)하면 학습 기록이 유지됩니다.

알아 두세요

  • 웹(2nhyeok.kr)에서 하던 기록은 웹의 나 → 백업 내보내기 → 앱의 나 → 백업 불러오기로 옮길 수 있어요.
  • iPhone은 앱 파일 설치가 안 됩니다. Safari로 2nhyeok.kr을 열고 공유 → 홈 화면에 추가를 이용하세요.
  • 앱 파일은 이 페이지(또는 GitHub Releases)에서만 받으세요.
